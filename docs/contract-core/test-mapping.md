now carries its promise, or marked n/a with the reason.

files named in `tools/check-test-mapping.py` (parametrised cases collapsed to
their test function). In the right column, paths are relative to the dora copy;
`DORA_NAV:` marks a path in the DORA_NAV copy; Rust unit tests are written
`file::tests::name`. Where a row names more than one test, together they carry
the promise. "Inverted by decision" marks a reference behaviour this slice
deliberately does the other way; the named test pins the new behaviour.
